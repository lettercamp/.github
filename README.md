# Lettercamp organization profile

This repository contains the public profile for the [Lettercamp GitHub organization](https://github.com/lettercamp).

Edit [profile/README.md](profile/README.md) to update the organization’s Overview page. The cover image is hosted on Lettercamp’s asset domain and links to the Lettercamp website.

Publish this repository as **`lettercamp/.github`**, with **public** visibility. GitHub displays `profile/README.md` on the organization profile automatically.
